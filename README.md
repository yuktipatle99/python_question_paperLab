Python Programming Lab

About the Project

This repository contains Python programs based on the Advanced Python Programming Question Paper.

The purpose of this repository is to practice Python programming concepts, understand their implementation, and improve problem-solving skills.

Topics Covered

The programs cover the following Python concepts:

- Boolean and Integer Operations
- Identity and Equality Operators
- Floor Division and Modulo
- List Slicing
- Tuple Unpacking and Extended Unpacking
- Closures and Nonlocal Keyword
- *args and **kwargs
- Set Operations
- Decorators
- Multiple Inheritance
- Generators
- Object-Oriented Programming (OOP)

Technologies Used

- Programming Language: Python
- IDE: Visual Studio Code
- Version Control: Git and GitHub

How to Run the Programs

1. Clone or download this repository.

2. Open the project folder in Visual Studio Code.

3. Open the terminal.

4. Run the required Python file using:
   
   "python filename.py"

This repository is created for academic learning and Python programming practice.
